# Osho Talks data

Data files for the [Osho Talks](https://apps.apple.com/app/id6774409039) apps.

The files are locked. Only the apps can read them, and nothing here is meant for use outside the apps. They are
on the branches `t0` to `tf`, not on this one.

Questions: [support page](https://github.com/aagrawal207/OshoDiscourses/blob/main/SUPPORT.md).
